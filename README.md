## 📁 What Projects Are Included?

| Project | Description | What You'll Learn |
| :--- | :--- | :--- |
| **Number Guessing Game** | A random number between 1 and 100 is generated. The user has to guess the number. The program gives hints ("Guess a larger number" or "Guess a smaller number"). Finally, it shows the total number of attempts. [File: `Guessing_game.c`] | `rand()`, `srand(time())`, `do-while`, `if-else` |
| **Digital Stopwatch** | The user enters a target time in hours, minutes, and seconds. The stopwatch then starts counting from `00:00:00` until the target time is reached, then displays "Time's up!" and stops. [File: `Digital_Stop_Watch.c`] | `while` loop, `sleep()` / `delay()`, countdown logic |
| **Digital Clock** | The user inputs an initial time (hours, minutes, seconds). Then the clock updates in real‑time, displaying in 24‑hour format with AM/PM. [File: `Only_digital_clock.c`] | Infinite loop, `system("CLS")` (screen clear), nested conditions, time increment |
